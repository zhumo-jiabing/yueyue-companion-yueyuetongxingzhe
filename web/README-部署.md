# 玥玥 · 展台部署说明（第88轮 · 局域网版）

> 这份文件是给**现场那台笔记本电脑**看的，不是给读者看的说明书。
> 按顺序做完 1–7 项，手机就能扫码说话；跳任何一项，现场都会出问题。

---

## 0. 一句话说明它是什么

一台笔记本当"服务器 + 假大脑"，观众用自己的手机连上这台笔记本的热点，打开网页，就能和玥玥说话。
**模型钥匙只在笔记本的进程内存里，永远不进手机。**

```
观众手机 ──(Wi-Fi 热点)──> 笔记本 8080 端口 ──(HTTPS)──> api.deepseek.com
                              │
                              ├─ /        落地页
                              ├─ /m       手机版对话（真源 index.html 实时注入）
                              └─ /api/chat 代理：限额、安全兜底、钥匙注入
```

## 1. 环境

| 项 | 要求 | 怎么确认 |
|---|---|---|
| Node.js | ≥ 18（只用自带模块 http/fs/path/os/https + vendor/qrcode.js，零 npm 依赖） | `node -v` |
| 端口 8080 | 没被别的程序占 | `netstat -ano \| findstr :8080` 应当没有 LISTENING |
| 笔记本无线 | 能开热点 | 设置 → 网络和 Internet → 移动热点 |
| 电源 | 全程插电，关闭睡眠 | 设置 → 系统 → 电源 → 屏幕和睡眠 = 从不 |

---

## 2. 放钥匙（唯一会碰到密钥的一步）

两种方式，二选一：

**方式 A（推荐现场）**：在 `K:\yueyueneiceban\web\` 下新建文件 `booth.key`，里面**只放一行**钥匙，不要引号、不要换行以外的空格。

**方式 B**：启动前 `set YUEYUE_KEY=sk-xxxx` 再启动。
> ⚠️ 绝对不要写成 `node proxy.cjs sk-xxxx` —— 密钥会出现在进程命令行里，任何本机进程都能读到。

**展台专用钥匙**：不要用你自己日常那把。去控制台单独建一把、设好额度上限，收场后直接吊销。

---

## 3. 启动

双击 `K:\yueyueneiceban\web\启动展台.cmd`，或手动：

```bat
cd /d K:\yueyueneiceban\web
node proxy.cjs
```

启动横幅会打印三行关键信息：

```
 本机打开 : http://localhost:8080/m
 手机打开 : http://192.168.x.x:8080/m
 模型钥匙 : 已加载（不打印，不在浏览器里）
```

**钥匙那一行必须显示"已加载"。** 显示 ❌ 就是没读到，先解决这个。
**如果出现「❗❗ 测试模式：这一台现在不能拿去展台 ❗❗」——立刻停手**，说明环境变量 `YUEYUE_MOCK_UPSTREAM=1` 还留着，模型是假的。

---

## 4. 开热点

> **老板已定：用手机热点**（手机开热点，笔记本连手机），不用笔记本开热点。
> 手机热点更稳：笔记本无线网卡省下来专心跑页面，热点由手机负责，电量也好控制。

做法：

1. 手机 →「个人热点」→ 打开，记下 **名称（SSID）与密码**，**必须与立牌写的一字不差**；
2. 笔记本连这个热点（连上后双击 `启动展台.cmd`（或 `node proxy.cjs`），横幅会打出新的局域网 IP）；
3. 频段优先 2.4 GHz（老手机兼容更好）；5 GHz 更快但部分旧机连不上；
4. 手机热点一般 **同时 8 台上限**（系统限制，未实测），人多时准备备用方案：
   - 第二台手机开第二个热点，立牌印两个 SSID + 两个二维码；或
   - 带一个独立 AP。

⚠️ 手机热点网段常见 `192.168.43.x` / `172.20.10.x`，**不要在任何文档里写死 IP**——`/qr` 永远按宿主当前 IP 当场生成，换网段就重新打开 `/qr` 再打印。

## 5. 防火墙（只放行一次）

以管理员身份运行一次：

```bat
netsh advfirewall firewall add rule name="Yueyue Booth 8080" dir=in action=allow protocol=TCP localport=8080 profile=private
```

放行范围选 **专用网络（private）**，不要选"任何网络"。

**同时确认三件事**（安全工程师口径，漏掉概率最高、后果最重）：
1. 路由器 **UPnP 已关闭**；
2. 没有配置端口转发 / DMZ；
3. 除 8080 外没有对外的监听端口（`netstat -ano | findstr LISTENING`），
   特别是桌面版自己的 9880（TTS 代理）—— 开场前确认桌面版没被带起来。

## 6. 开场前自检（3 分钟，手机做）

1. 手机连上热点 → 浏览器打开 `http://<横幅里的IP>:8080/`
2. 点「和她聊两句」→ 应看到年龄门
3. 选「18 岁以上」→ 二次确认 → 同意门（勾选后才能继续）
4. 进入对话 → 她对你说第一句话 → **点一下任意位置，听有没有声音**
5. 打一句「你叫什么名字」→ 看是否流式回字
6. 打开 `http://<IP>:8080/m?selftest=1` → **全绿才算过**

自检面板里只要有一项红，就不要开展。

---

## 7. 收场

1. `Ctrl+C` 停代理
2. 去控制台**吊销展台钥匙**
3. 把 `web\booth.key` 删掉（不要留在磁盘上）
4. 日志文件（如果重定向了）一并删除

## 附：现场出问题怎么查

| 现象 | 先看这里 |
|---|---|
| 手机连不上 | 同一热点？IP 变了？防火墙？ |
| 打开是白屏 | `?selftest=1` 面板 |
| 说"还没配好钥匙" | 横幅「模型钥匙」那行 = ❌ |
| 有字没声 | iOS 静音键 / 浏览器静音；网页版语音默认开 |
| 提示额度用完 | `/api/capabilities` 的 `daily`；当天只能等明天 |
| 报 421 | 访问用的域名不在白名单（用 IP 直连） |
| 报 403 | 路径穿越保护（正常） |

## 附：立绘怎么换

手机版和落地页现在共用 `web\yueyue_avatar.webp`（1080 宽、q78、约 93 KB，第 96 轮压缩版）。
新图做好后：

1. 导出 **1080×1440 WebP（q78，≤200KB）**
2. 覆盖 `K:\yueyueneiceban\web\yueyue_avatar.webp`
3. 刷新落地页 `/` 与手机版 `/m` 确认不糊、文字仍可读（landing.html:127 引 webp，
   onerror 回落 `/yueyue_avatar.png`；m.css 只调 `--m-figure` 遮罩，不动 src）

> 立绘是 3:4 竖图、脸在画面上半部。透明底最好；不透明底请让背景色接近 `#E7EDF4`，
> 手机版会自动用遮罩把它压成光晕。
