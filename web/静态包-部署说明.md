## 一、先确认一件事

上传时要上传 **`dist-static` 里面的内容**，不是 `dist-static` 这个文件夹本身。
判断标准：上传完成后，网站**根目录下**应该直接是 `index.html`，而不是 `dist-static/index.html`。

拖拽上传（Vercel / Netlify）可以直接把整个 `dist-static` 文件夹拖进去，它们会自动把里面当根目录；用 GitHub Pages 或 FTP 时要注意这一点。

## 二、三种上传方式（按省事排序）

### 方式 A：Vercel 拖拽（最省事，3 分钟，免费）

1. 打开 <https://vercel.com>，用 GitHub / 邮箱注册（免费）。
2. 首页 → **Add New… → Project → Deploy**，或者直接进 <https://vercel.com/new>。
3. 页面底部有 **"Deploy a template"** 旁边的 **拖拽区**（或从 Dashboard → 右上角 **Import** → 选 **"Deploy without Git"**）。
4. 把 `dist-static` 文件夹拖进去 → Deploy。
5. 完成后给你一个 `xxx.vercel.app` 的地址，直接能用。

- 优点：不用装东西、无命令行、HTTPS 自动有、免费额度足够。
- 缺点：**国内访问有时慢或打不开**（Vercel 的域名在国内没有节点）。如果主要给国内的人看，建议同时试方式 B，或者自己在国内买台轻量服务器（见第四节）。

### 方式 B：Netlify Drop（同样拖拽，免注册可先试）

1. 打开 <https://app.netlify.com/drop>。
2. 把 `dist-static` 文件夹拖进去。
3. 立刻给你一个 `xxx.netlify.app` 地址（不登录也能生成，但**不登录的站点 1 小时后会消失**，所以还是注册一下）。

- 国内访问情况和 Vercel 差不多，可以两个都试，哪个快用哪个。

### 方式 C：GitHub Pages（免费、长期、要几步操作）

1. 注册 GitHub → 新建一个仓库，名字随意，比如 `yueyue`，**Public**。
2. 把 `dist-static` 里的**内容**全部上传到仓库根目录（网页上 Add file → Upload files，把文件拖进去，注意是"里面的内容"，让 `index.html` 在根目录）。
3. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch** → Branch 选 `main` / `(root)` → Save。
4. 等 1–2 分钟，地址是 `https://你的用户名.github.io/yueyue/`。

- 优点：永久免费、不会被限流、国内一般能打开（偶尔慢）。
- 缺点：仓库是公开的（这些内容本来就是给公众看的，没有问题）；以后更新要重新上传。

## 四、几件必须知道的事

**1. 网站能做的只有"宣传"，不能在线聊天。**
页面里原来的「和她聊两句」按钮已经换掉了——因为在线试玩要连你本机的那段转发程序（还要 API 钥匙），静态托管上没有这些，点进去必然报错。钥匙更不能挂到公网上。所以公网页只负责：让她露脸、讲清楚她是什么/不是什么、给群码。

**2. 国内访问速度。**
Vercel / Netlify / GitHub Pages 都在境外，国内打开可能慢、偶尔失败。要稳定给国内的人看，正规路子是：在国内云买一台轻量服务器（阿里云 / 腾讯云，几十块一个月）+ 一个域名 + **ICP 备案**（企业或个人，7–20 工作日）。**只用境外托管不备案是允许的**，但一旦用国内服务器 + 域名对外提供网页，就必须备案，这是硬规定。漫展现场用二维码的话，境外托管一般也能扫开，可以先这样用。

**3. 微信里打开可能提示"非微信官方网页"。**
这是微信对站外链接的常规提示，不影响访问；要完全避免只能用微信公众号/小程序，那是另一条路。

**4. 关于合规标注。**
页面里已保留「图像由 AI 生成」小字、`policy.html` 里的隐私与边界说明、以及"仅限 18 岁以上"。这三样是上线前必须留着的，不要为了好看删掉。

**5. 更新内容怎么办。**
改了 `web/landing.html` 或换了立绘之后，重新跑一次：
```
cd K:\yueyueneiceban\web
python build-static.py
```
它会把 `dist-static` 重新生成一遍并自检（有没有残留绝对路径、资源是否齐全），然后重新上传/推送即可。立绘源图在 `build-static.py` 顶部的 `HERO_SRC` 里改。

## 第 4 版变更记录（2026-10-28 夜）

### 一、配色从深色改成浅色

老板原话：「网页颜色不要那么过于深，不要弄的像普遍的 AI 网页和诈骗网页一样，不要弄的让用户无法放心。」

- 底色 `#0b0916`（近黑）→ `#FAF8F4`（暖白纸），卡片 `#FFFFFF`
- 正文 `#ece8f7`（冷白）→ `#23211E`（暖黑），次要文字 `#5C5850`
- 强调色只留一个：玫红 `#A8436A`（按钮、小标题圆点、加粗词）；金色压深到 `#8A6A22`，紫色压深到 `#5C4E86` —— 都按对比度选过，正文对纸底 6.6:1、玫红 5.4:1、暗金 4.8:1、紫 6.8:1
- 立绘区从「深色渐变 + 大阴影」改成「白卡 + 1px 描边 + 淡阴影」
- 二维码/收款码的虚线占位框改成实线卡（码已经是真图了，虚线框看着像没做完）

改动只碰 `web/landing.html` 与 `web/support.html`；`policy.html`（隐私政策）**一个字没动**，它在 app 里也在用。

### 二、双击就能看

`web\启动宣传页.cmd` —— 双击它，会自动起一个本机小服务并打开浏览器。

- 地址：`http://127.0.0.1:8091/`
- 关掉那个黑窗口 = 停止
- 它自己找 Python：先找 GPT-SoVITS 自带的 runtime，找不到再找系统的 `python` / `py`
- 找不到 Python 时也会提示：把 `dist-static` 拖到 https://app.netlify.com/drop 也能得到一个网址

踩过的坑（写给以后的我）：.cmd 文件必须是 **GBK 编码 + CRLF 换行**。UTF-8 会在 cmd 里变成乱码；GBK 但只有 LF 换行时，每行第一个字符会被吃掉（`echo` 变成 `ho`），结果一样跑不起来。
