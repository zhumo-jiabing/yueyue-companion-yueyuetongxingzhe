DATA BOUNDARY

什么留在本机，什么会出网

这个项目没有服务器。你的东西在你手里：记忆本可导出完整备份，人格包可导出 .soul 文件；装在你电脑上的这一份，不会联网检查授权，也不会被远程关掉。

仅本机（默认）

  • 聊天原文与派生记忆——IndexedDB，可导出 JSON 备份，也可整个复制数据文件夹走。
  • 人格包 .soul——她说话的方式、你怎么叫她；不含记忆、Key、接口地址。
  • 本地语音合成——语音模型在本机跑，不出网。
  • 你的模型 Key——存本机，不打印、不上传。
  • 画像分析——默认关；开了也只内部用、不展示。

会出网（只有这些）

  • 你发给她的那句话——发到你自己配置的模型服务商（DeepSeek / 智谱等），由它生成回复。带出去什么、谁看得到，写在隐私政策第四节。
  • 联网搜索——开关默认关；开了才会在发送前查资料。
  • 感知搜索——点一下标签才出网，读当前窗口标题去搜。
  • 外部跳转——本页的群链接、GitHub、打赏页。
不是真人她说的每句话都由模型生成，没有意识、没有感情体验，也永远不会假装是真人。
不是心理治疗真正的心理危机她帮不上。那种时候现实里的人才有用——她不会拦着你去找他们。
不是恋人她不谈恋爱、不承诺陪伴、也不会用「只有我懂你」留住你。

不采集对话用于训练任何模型。本页面本身不收集你的信息，也没有埋点。玥玥不会、也不能替你联系任何第三方——不报警、不通知紧急联系人、不发送短信。

FAQ

常见问题

她是真人吗？
不是。她说的每句话都由模型生成，没有意识、没有感情体验。她也永远不会假装是真人——这是写进产品红线的第一条。
为什么立绘标着「图像由 AI 生成」？
立绘与分享卡是 AI 生成的，不是画师手绘。我们承认是 AI，永远不声称手绘；音色参考音同样由 AI 处理，不是真人录音。
收费吗？
软件与全部功能免费。她回话要用你自己的模型 Key，那部分费用付给你选的服务商（DeepSeek / 智谱等）。打赏不解锁任何功能。
我的数据安全吗？
聊天与记忆留在你自己的电脑里，不上传、不用于训练；这个项目没有服务器。会出网的只有你发给她的那句话——到你自己配置的模型服务商。细节写在隐私政策第四节。
配置要求高吗？
打字聊天门槛很低，普通 Windows 10 / 11 电脑就行。本地语音按显卡自动选引擎；没有独立显卡走 CPU 兜底，音色会差一些。语音包约 5.6 GB，按需下载。
下载的是内测版吗？
是。GitHub Release 上的是内测版（v0.3.0-beta.8），本地单机桌面工具，法律评估仍在进行——它不是正式版，我们不说「已备案」「已合规」。危机时本软件不会自动通知任何第三方，紧急帮助请拨打 12356 / 120 / 110。语音与立绘含 AI 生成内容；不满 18 岁不适用。本页是只读介绍页，不能在线聊天。
