# dataset_skeleton · 玥玥情绪分类 500 条最小标注集模板

> 配套: samples_template.jsonl(40 条起步样例) / train_emotion.py(训练+导出) / emotion-classifier.js(推理)
> 权威 8 标签(14-integration-guide §0 拍板4, 不可改): 开心 / 难过 / 生气 / 焦虑 / 思念 / 期待 / 平静 / 疲惫

## 1. 数据格式(JSONL, UTF-8 无 BOM)

每行一条:

    {"text": "今天发工资啦！晚上请你吃火锅！", "label": "开心"}

- text: 2-30 字口语短句(不含首尾空白); 语气词/省略号/emoji 允许
- label: 必须属于 8 标签之一
- 以 # 开头的行是注释(训练脚本自动跳过)

## 2. 500 条最小集的均衡建议

| 标签 | 建议条数 | 备注 |
|---|---|---|
| 开心 | 60-65 | 最易, 可少给 |
| 难过 | 60-65 | 与 思念/疲惫 易混, 宁多勿少 |
| 生气 | 60-65 | 口语特征明显(脏话/感叹) |
| 焦虑 | 60-65 | 与 难过 易混(担心 vs 失落) |
| 思念 | 60-65 | 与 难过 易混(有明确对象→思念) |
| 期待 | 60-65 | 与 开心 易混(未发生→期待) |
| 平静 | 60-65 | 短回应/陈述句; 运行时长度规则会再兜底 |
| 疲惫 | 60-65 | 与 难过 易混(累 vs 伤心) |

## 3. 标注规则(10 条)

1. 用户视角: 想象这是用户对玥玥说的话(第一人称口语), 不是新闻/评论/书面腔
2. 口语保真: 保留语气词(嘛/呀/啦/唉/哼/啧/哦)、省略号、重复、emoji(😂😠😭 允许)
3. 忌标签字面词: 尽量不让 text 出现"开心/难过/生气/焦虑/疲惫"等标签词本身(用语境表达: "笑死我了" 而不是 "我很开心"), 防止模型只学关键词
4. 一条一个标签: 混合情绪标主导情绪; 实在两可 → 标"平静"或直接剔除
5. 防御式否认句("我没事""我很好"): 按真实情绪标(如 "我没事，真的没事" → 难过); 运行时由 emotion-classifier.js 克制规则 R2 兜底不贴(16-testcases 表A #8)
6. 短回应("哦/嗯/好的"): 标"平静"(运行时长度规则会不贴)
7. 思念 vs 难过: 有明确想念对象(某人/家/梦见) → 思念; 自我否定/失落 → 难过
8. 期待 vs 开心: 事情还没发生、盼着发生 → 期待; 已经发生/当下正爽 → 开心
9. 焦虑 vs 疲惫: 有具体担心(考试/面试/没钱) → 焦虑; 单纯累/不想动 → 疲惫
10. 版权红线: 只自写/自改, 不要整句搬运微博/豆瓣/贴吧等平台语料(商业分发风险)

## 4. 标注来源建议(按优先级)

1. 自写(最佳): 按规则 1-10 直接写, 每天 50 条一周完成
2. 改写: 用 LLM 按规则 1-10 生成候选句, 人工逐条改到口语自然
3. 真实语料: 用户自己的聊天记录(征得同意), 脱敏后标注 —— 最贴目标
4. 表A 移植: 16-testcases 表 A 的 10 条(除 #6/#8 两条克制用例外)直接进训练集

## 5. 扩数据路径(500 条不达标或想提质时)

按 train_emotion.py 输出的验证集 macro-F1 决定:

- macro-F1 >= 0.65: 可接线; 想提质 → 补难例(把 --eval-lines 与真实使用中错判的样本人工复核后入集)
- 0.55-0.65: 每类补到 100+(共 800+), 优先补低频混淆对(思念↔难过、期待↔开心、平静↔疲惫)
- < 0.55: 必须扩到 2000+(每类 250+); 仍不达标 → 换 bge-base-zh-v1.5 重训或 Qwen3-0.6B 微调(12-emotion 备选2)

技巧: 同义改写(换句式/语气词/emoji)可把 500 变 1500, 但每条原句最多 3 个变体(防句式过拟合)。

## 6. 标注质量自检

- 随机抽 20 条, 两人独立盲标, 一致率 >= 85% 才进训练集
- 每类抽 3 条检查规则 3(无标签词泄漏)
- 类分布以 train_emotion.py 启动时打印为准(目标每类 60-65)
