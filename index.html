❓ 常见问题（第一次用建议看一眼）
她说"还没放钥匙"？去设置里填当前所选模型的 API Key：默认档 DeepSeek（platform.deepseek.com 免费注册 → 创建 API Key → 粘贴）；切到智谱 / 通义档就填那一家的 Key。
没有声音？语音是可选的本地组件：开启语音后首次会启动本地服务（可能等 10-60 秒）；设置页「一键体检」会告诉你缺什么。
语音是怎么来的？她的声音由本机 AI 语音合成模型实时生成（不是真人录音）：长句逐句合成需要等待（每句可达 1-2 分钟），AI 合成的每一段都可能略有差异；生成期间可以先看文字，声音会随后补上。
陪看抓不到画面（黑的）？游戏改「窗口/无边框窗口」模式即可，全屏独占模式系统不允许抓帧。
电脑变卡？长时间不用语音时本地语音服务会自动退出释放内存（约 5 分钟）；也可以在设置里换更省的模型档。
我的数据在哪？全部在本机（Electron userData 目录）；功能地图里有「本地使用统计」可查看/导出/清除；心之记忆本可导出 JSON。
她会不会乱说话？她由大模型驱动，可能出错；她不会自称真人，也不会编造你的经历——发现不对可以直接告诉她，或去设置里换模型。
怎么反馈问题？设置页「📋 复制诊断信息」把环境信息复制出来，连同截图/描述发给开发者即可（不含聊天内容与 Key）。
隐私政策和用户协议在哪？在设置页、更多菜单、首次引导页和这里都能打开，在应用内直接显示，不会跳转到外部浏览器。📜 现在打开《隐私政策》与《用户协议》
